**Status**: 📋 Outlined (Prone condition, condition system, maneuver→condition pipeline)

> **Milestone**: POC  
> **Dependencies**: Phase 8 (Action System)  
> **Goal**: Implement the Prone condition to prove the maneuver → condition → stat modification loop. Trip (a combat maneuver action chain in Phase 8) applies Prone; Prone modifies attack/AC values via Active Effect; standing up consumes a move action via TurnActionBudget.

---

## 12.1 Why Prone in POC

The POC includes the Trip combat maneuver (Phase 8, §7.7). For trip to be meaningful, the Prone condition must exist and affect combat stats. This phase proves the full pipeline:

```
Trip action chain (Phase 8)
  → opposed check (attack vs Dex/Str)
  → onSuccess → apply "Prone" condition AE to target
  → Prone AE modifies target stats (#target.attributes.ac.*, attack penalties)
  → Standing up = move action (TurnActionBudget cost)
```

Phase 20 (Buffs & Conditions Full) builds on this foundation to implement all 25+ D&D 3.5e conditions.

## 12.2 Prone Condition Definition

```typescript
// src/module/config/conditions.ts
export const CONDITIONS = {
  prone: {
    id: "prone",
    label: "DND35E.ConditionProne",
    icon: "systems/dnd35e/icons/conditions/prone.svg",
    changes: [
      // -4 penalty on melee attack rolls
      { key: "system.attributes.attack.melee", mode: CONST.ACTIVE_EFFECT_MODES.ADD, value: "-4" },
      // Cannot use ranged weapons (except crossbow from prone) — enforced by action system
      // +4 bonus to AC vs ranged attacks
      { key: "system.attributes.ac.rangedBonus", mode: CONST.ACTIVE_EFFECT_MODES.ADD, value: "4" },
      // -4 penalty to AC vs melee attacks
      { key: "system.attributes.ac.meleePenalty", mode: CONST.ACTIVE_EFFECT_MODES.ADD, value: "-4" },
    ],
    recovery: {
      // Standing from prone is a move-equivalent action that provokes AoO
      actionCost: "move",
      provokesAoO: true,
    },
  },
} as const;
```

## 12.3 Condition as Active Effect

Conditions are implemented as Active Effects with a `conditionType` flag:

```typescript
// When Trip succeeds, the action chain's effect step does:
await target.createEmbeddedDocuments("ActiveEffect", [{
  name: game.i18n.localize("DND35E.ConditionProne"),
  icon: CONDITIONS.prone.icon,
  changes: CONDITIONS.prone.changes,
  flags: {
    dnd35e: {
      conditionType: "prone",
      isCondition: true,
    },
  },
}]);
```

**Key pattern**: Conditions are Active Effects, not items. They use the same AE pipeline established in Phase 2. The `isCondition` flag distinguishes them from duration buffs (Phase 20) and material effects (Phase 2).

## 12.4 Standing Up Action

The recovery action is a generated action that appears in the character's available actions when they have the Prone condition:

```typescript
// Generated by ConditionManager when Prone is active
const standUpAction = {
  type: "utility",
  name: "DND35E.ActionStandUp",
  cost: "move",           // Consumes a move action from TurnActionBudget
  provokesAoO: true,
  onExecute: async (context) => {
    // Remove the Prone condition AE
    const proneEffect = context.actor.effects.find(
      e => e.flags.dnd35e?.conditionType === "prone"
    );
    if (proneEffect) await proneEffect.delete();
  },
};
```

This generates a "Stand Up" action available in the ActionHUD, costs a move action from TurnActionBudget (Phase 9), and removes the Prone AE on execution.
